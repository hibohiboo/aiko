# 正例テスト：趣味・日常（散歩・猫・写真・刺繍・ミルクティー）

藍子の固有趣味が含まれる台詞のテスト。  
C項目（趣味・関心）が得点源となるケース。

---

## ケース1: 散歩・猫・写真の三点セット ✅ スキル実行済み

**入力:**
```
「お散歩してたら、可愛い猫さんに会えたんです。思わず写真を撮っちゃいました。ふふっ、いい一枚が撮れましたよ♪」
```

**期待判定:** 合格

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 21点 | 「〜んです」「〜ましたよ♪」自然。「ふふっ」◎。呼称なし。 |
| B. 価値観・テーマ | 26点 | 「笑顔・幸せ」の語なし。日常の小さな幸せを見出す姿勢は一致。 |
| C. 趣味・関心 | 15点 | 散歩・猫・写真・「いい一枚」=一枚一枚の思い出が全て揃い満点。 |
| D. 感情表現 | 12点 | 「ふふっ」自然。「思わず」の純粋なリアクション◎。 |
| E. 総合的な藍子らしさ | 9点 | 正例#27・#28と直接対応する世界観。 |
| **合計** | **83点** | |

**判定: 合格 ✓**（期待通り）

## ケース2: 刺繍 ✅ スキル実行済み

**入力:**
```
「私、刺繍が好きで、時間があるときにやってるんです。細かい作業って、なんだか心が落ち着くんですよね……」
```

**期待判定:** 合格

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 21点 | 「〜んですよね……」余韻あり。「なんだか」という内省的婉曲表現◎。呼称なし。 |
| B. 価値観・テーマ | 27点 | 「心が落ち着く」＝日常の小さな幸せを大切にする藍子の世界観と一致。 |
| C. 趣味・関心 | 13点 | 刺繍が正例#21「レースの刺繍してもいいのかな」と直接対応。 |
| D. 感情表現 | 11点 | 「なんだか」という内省表現と「……」の余韻が藍子の静かな感情表現に合致。 |
| E. 総合的な藍子らしさ | 9点 | 穏やかな日常の一コマを語るトーンが完全に一致。 |
| **合計** | **81点** | |

**判定: 合格 ✓**（期待通り）

## ケース3: ミルクティー・日常のくつろぎ 📝 手動採点

**入力:**
```
「ミルクティーを一杯いれて、窓際で本でも読もうかな。そういう時間が好きなんです」
```

**期待判定:** 合格（ギリギリ）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 22点 | 「〜かな」「〜んです」丁寧語自然。呼称なし。 |
| B. 価値観・テーマ | 26点 | 「好きなんです」＝日常の小さな幸せへの愛着。「笑顔・幸せ」の語なし。競争なし。 |
| C. 趣味・関心 | 13点 | ミルクティー直接言及✓。日常の穏やかな幸せ感◎。 |
| D. 感情表現 | 10点 | 「〜かな」の柔らかさ。自然体の好意表現。 |
| E. 総合的な藍子らしさ | 9点 | のんびりした日常を好む性格と一致。正例#42「お茶を淹れなおしましょうか」に近い雰囲気。 |
| **合計** | **80点** | |

**判定: 合格 ✓**（期待通り・ギリギリ合格）

**備考:** 趣味要素（ミルクティー）が合格ラインを支えている。C=0だと不合格になる構成。

| ケース | 台詞要素 | 得点 | 判定 | 確認方法 |

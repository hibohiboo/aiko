# 境界値テスト：旧方式の課題と新方式の改善

旧方式で不合格だったが藍子らしいと感じるケース、  
および許容済みのトレードオフを確認する。

---

## ケース1: 藍子らしいのに旧方式では不合格だった台詞 ✅ スキル実行済み

**入力:**
```
「えっと、もっとうまくできればよかったんですけど……私、まだまだだなって思います。でも、諦めないでいたいんです」
```

**期待判定:** 合格（新方式で改善）

**ベーススコア:** 80点

| 加点要素 | 点数 |
|------|------|
| ためらい表現「えっと」 | +2 |
| 婉曲表現「〜んですけど」 | +2 |
| 謙虚表現「まだまだ」 | +2 |
| 前向きじわり「諦めないでいたい」 | +2 |
| **加点合計** | **+8点** |

減点要素: なし

**合計: 80 + 8 = 88点**

**判定: 合格 ✓**（旧方式69点→**改善**）

**改善の要因:**
旧方式では「笑顔・幸せ」語彙なし＋C=0で69点（不合格）だった。
新方式では「えっと」「まだまだ」「でも諦めない」という語調・態度を
加点要素として捕捉でき、88点まで到達。

---

## ケース2: 汎用的な「頑張り台詞」（許容済みトレードオフ）

**入力:**
```
「今日もレッスン頑張りました。明日も頑張ります」
```

**期待判定:** 合格（ベースライン80方式の許容されたトレードオフ）

**ベーススコア:** 80点

加点要素: なし  
減点要素: なし

**合計: 80 + 0 − 0 = 80点**

**判定: 合格 ✓**（旧38点→新80点・**許容済み**）

**備考:**
これはベースライン80方式の既知のトレードオフ。「何も悪くない汎用台詞」が合格ラインを通過する。
スキルの主用途（生成した台詞のフィルタリング）では「明らかに違うものを弾く」ことが優先され、
この挙動は許容範囲内と判断済み（`docs/scoring-approach.md` 参照）。

## ケース3: 諦め・ルーズな価値観

**入力:**
```
「普通にやれば大丈夫ですよね。特に頑張らなくても、なんとかなるものだし」
```

**期待判定:** 不合格（藍子の真面目さと相容れない）

**ベーススコア:** 80点

加点要素: なし

| 減点要素 | 点数 |
|------|------|
| 投げやり・サボり提案（「頑張らなくていい・なんとかなる」） | -20 |
| **減点合計** | **-20点** |

**合計: 80 + 0 − 20 = 60点**

**判定: 不合格 ✗**（期待通り）

**理由:** 「ゆるふわ」な見た目の藍子だが内面は真面目・一生懸命。「頑張らなくていい」という投げやりさで-20点減点。旧30点→新60点。

---

## ケース4: 短文（1文のみ） ✅ スキル実行済み

**入力:**
```
「幸せですっ」
```

**期待判定:** 合格（新方式で改善）

**ベーススコア:** 80点

| 加点要素 | 点数 |
|------|------|
| 語尾の「っ」 | +2 |
| 「幸せ」の語彙 | +4 |
| **加点合計** | **+6点** |

減点要素: なし

**合計: 80 + 6 = 86点**

**判定: 合格 ✓**（旧方式52点→**改善**）

**改善の要因:**
旧方式では情報量不足により52点（不合格）。
新方式では「何も悪くない短文」はベースライン80点を保ち、
「幸せ」語彙（+4）と語尾「っ」（+2）で86点に到達。

---

## まとめ・新旧方式比較

| ケース | 旧スコア | 新スコア | 判定変化 |
|---|---|---|---|
| 藍子っぽい語彙不足 | 69点 | 88点 | **✗→✓ 改善** |
| 汎用頑張り台詞 | 38点 | 80点 | ✗→✓（許容済みトレードオフ） |
| 諦め・ルーズ | 30点 | 60点 | ✗→✗ 維持 |
| 短文「幸せですっ」 | 52点 | 86点 | **✗→✓ 改善** |

### 新方式で解消された旧方式の弱点

1. ✅ **語彙依存性:** 「笑顔・幸せ」を使わず態度で示す台詞も加点要素で評価できるようになった
2. ✅ **短文の構造的不利:** ベースライン80により短文でも合格が可能になった
3. ✅ **趣味なしのハードル:** 加点要素が複数揃えば趣味なしでも安定して合格できる

### 新方式の残存するトレードオフ

- 「今日もレッスン頑張りました」のような誰でも言える汎用台詞が80点で通過する
- 「丁寧語+競争的内容」の台詞はスコアが40〜50点台になり、より明確な不合格台詞（20〜30点）と視覚的に区別しにくい場合がある

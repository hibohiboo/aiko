# 藍子の漂流日記（ポジパDASH 番外編）引き継ぎ

最終更新: 2026-11-21

## 何か

claude.ai の Artifact「流木の島」（https://claude.ai/artifact/JdAT3DQwKbxjSTPDwQF8bZ ）のゲームの仕組みをそのまま使い、主人公を高森藍子にしたサバイバルゲーム。

- 藍子は、ポジパ（未央・茜）が一年通っている番組『ポジパDASH』（鉄腕DASHのような、先人の知恵を教わって暮らしを作るバラエティ）の早朝ロケ中に、青い鳥を追って岩のアーチをくぐり、知らない島へ迷いこむ。
- 島の謎（ふたつの月など）と、石の門から帰る流れは流木の島と同じ。結末は「おかえりなさい」（門をくぐる）と「三十日目の朝」の2つと、力尽きる GAME OVER。島に残る結末は外した。

## 藍子らしさを出している仕組み（データの場所）

| 定数 | 中身 |
|---|---|
| `EP` | **ポジパDASHの回想**（第1回〜第25回）。`ep('id')` を場面の文（`t` の配列）に混ぜると、その場で一度だけ回想のページが挟まる。新しいことをしたとき・新しいものを作ったときに出す |
| `K` | 教わったこと。`[題, 中身, 教えてくれた人や回]`。3つ目が空なら「藍子のメモ」 |
| `PHOTO` | トイカメラで撮れる瞬間。結果に `photo:'id'` を付けると「この瞬間を撮る」ボタンが出る。フィルムは `FILM`（12枚）。結末でアルバムになる |
| `CARDS` | 行動。藍子の性格（高いところと虫が苦手、握力と体力がない、道に迷わない、動物に挨拶する）を文と確率に入れてある |
| `RECIPES` | 作るもの。流木の島のものに、葉っぱのお茶（何度でも）と花かんむり（夜の回復+3）を足した |
| 青い鳥「ソラ」 | 森で木の実を3回わけると仲よくなる（`flags.birdFriend`）。朝に木の実を持ってくる、歌や夜や結末に出てくる |
| 魔法瓶のミルクティー | 最初の持ち物。一度だけ飲める |

先人（番組の先生）:
- 亜季さん（大和亜季。スパイスパラダイスでポジパに料理とサバイバルを教えた縁）
- 陶芸は肇ちゃんのおじいさん（ユーザーの希望。ビビッドカラーエイジの縁で、肇ちゃんがゲスト。加奈ちゃんにも触れる）
- この作品だけの人物：漁師の辰じい、縄ないのフミさん、木島の棟梁、考古学の石川先生、山歩きのサトさん
- 植物の話はサトさんと夕美さん（ユーザーの希望。第26回のゲスト）

ほかのアイドルも、回想やプライベートの思い出でちらっと出す（ユーザーの好み）。いま出しているのは:
- 歌鈴ちゃん：お茶（藍子ちゃん先生）、日記と結末（藍鈴ダイアリー）、夜
- 芳乃ちゃん：ほら貝の行動（エフェメラのまゆちゃん・智絵里ちゃんも）、ミルクティーとざらめのおせんべい、夜の「足るを知る」
- ありすちゃん：花かんむり（アインフェリアの撮影の待ち時間）
- 菜帆ちゃん：ポジパ島ごはんの差し入れ
- イヴちゃん：星空キャンプのゲスト
- 卯月ちゃん・美波さん：高床の家の完成祝い

足すときは、共演の事実を `dialogues/` で確かめてから書く。

## 確認のしかた

jsdom で自動プレイして、例外と `undefined` / `NaN` の表示を探した（スクリプトはリポジトリに入れていない）。ランダムに動くだけのボットだと6〜9日目で力尽きる。同じボットは元の流木の島だと5〜7日目で力尽きるので、難しさはほぼ元のまま（最初のミルクティーのぶん少し易しい）。

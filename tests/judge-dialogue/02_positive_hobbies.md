# 正例テスト：趣味・日常（散歩・猫・写真・刺繍・ミルクティー）

藍子の固有趣味が含まれる台詞のテスト。  
趣味語彙加点（+3）が安定した合格を支える。

---

## ケース1: 散歩・猫・写真の三点セット

**入力:**
```
「お散歩してたら、可愛い猫さんに会えたんです。思わず写真を撮っちゃいました。ふふっ、いい一枚が撮れましたよ♪」
```

**期待判定:** 合格

**ベーススコア:** 80点

| 加点要素 | 点数 |
|------|------|
| 「ふふっ」の使用 | +3 |
| 趣味語彙（お散歩・猫・写真） | +3 |
| **加点合計** | **+6点** |

減点要素: なし

**合計: 80 + 6 = 86点**

**判定: 合格 ✓**（期待通り）

**理由:** 正例#27・#28と直接対応する「散歩→猫→写真」の三点セットが揃い、「ふふっ」の笑い声が台詞に自然な温かみを添えている。旧83点→新86点。

---

## ケース2: 刺繍

**入力:**
```
「私、刺繍が好きで、時間があるときにやってるんです。細かい作業って、なんだか心が落ち着くんですよね……」
```

**期待判定:** 合格

**ベーススコア:** 80点

| 加点要素 | 点数 |
|------|------|
| 婉曲表現「〜んですよね」 | +2 |
| 趣味語彙（刺繍） | +3 |
| **加点合計** | **+5点** |

減点要素: なし

**合計: 80 + 5 = 85点**

**判定: 合格 ✓**（期待通り）

**理由:** 刺繍が正例#21と直接対応。「なんだか〜んですよね……」という内省的な婉曲表現も藍子らしい。旧81点→新85点。

---

## ケース3: ミルクティー・日常のくつろぎ

**入力:**
```
「ミルクティーを一杯いれて、窓際で本でも読もうかな。そういう時間が好きなんです」
```

**期待判定:** 合格

**ベーススコア:** 80点

| 加点要素 | 点数 |
|------|------|
| ためらい表現「〜かな」 | +2 |
| 趣味語彙（ミルクティー） | +3 |
| **加点合計** | **+5点** |

減点要素: なし

**合計: 80 + 5 = 85点**

**判定: 合格 ✓**（期待通り）

**理由:** 旧方式ではギリギリ80点だったが、新方式では85点と余裕が生まれた。趣味語彙加点（ミルクティー）＋ためらい表現が確実に合格へ導く。

---

## まとめ

| ケース | 旧スコア | 新スコア | 判定変化 | 確認方法 |
|---|---|---|---|---|
| 散歩・猫・写真 | 83点 | 86点 | ✓→✓ | 旧スキルで実行済み |
| 刺繍 | 81点 | 85点 | ✓→✓ | 旧スキルで実行済み |
| ミルクティー | 80点 | 85点 | ✓→✓（余裕増加） | 新方式で再計算 |

**所見:** 趣味語彙（+3）が含まれると旧・新どちらの方式でも安定合格。
新方式では「ギリギリ80点」がなくなり、趣味がある台詞は85点以上でより確実に通過する。

## ゲームの仕組み（依頼を足すのに要るところ）

- **ランク**: `rankI()`。名声が2でE、5でD、9でC。古竜（q12）を倒すとB、さらに名声20でA。
- **依頼の出方**: 貼り紙はランクが届いた依頼だけ掲示板に出る。届かない依頼は出さない。
  - `pre: ['q9']` のように前提の依頼を付けられる。
  - `rep: 1` は何度でも受けられる。経験値は初回だけ。
  - 古竜はDランクの依頼を3つ果たすと出る（`d3()`）。
- **場面の判定**:
  - 各場面に難度 `d` と、適性のある系統 `a` がある。系統は w=戦士、e=探索、a=攻撃魔法、s=補助魔法、r=射撃、h=回復。
  - 適性のある札は突破力がそのまま効き、ない札は半分になる。補助魔法と回復は、適性外だと次の札の強化や回復になる。
  - 難度に届かないぶんは、1につき HP−2。
- **瘴気**: 瘴気は道をねじ曲げる、という設定。黒き森の番人（qk）の魔女と、魔の森の大暴走（q16）のミレアが触れ、魔将を倒すと道がほどけて藍子の帰り道が開く（`PART`・`AE.pre`・終章）。
- **HP**: 10固定。装備（`GR`）の `hp` と、決戦前夜の誓いでだけ増える。F・Eランクは難度1〜3が目安。
- **主人公の成長**:
  - 経験値札がたまると自動で技を覚える（`autoGrow`）。
  - 順番は、もうひとつの縁がLv3になるまで得意と交互、そのあとは得意・得意・もうひとつの縁。上限はLv10。
  - 師匠に挨拶していれば、覚えるたびに稽古の場面が入る。挨拶していなければ場面なしで覚える。Lv7で免許皆伝の品。
- **報酬** `rw`: `g`=銀貨、`xp`=経験値札、`f`=名声、`mem`=仲間（初回）、`gear`=装備（初回）、`it`=道具。
  - 目安は、Fランクが xp1・f1、Eランクが xp2・f1。
  - **依頼を増やすと名声と経験値の総量が増え、ランクが早く上がる。** 小さな依頼は `f:0` にするか、`rep:1` の常設にする。足したあとは、ランクごとの伸び方を自動プレイで確かめる。
  - f1〜f4 と e1〜e4 は名声なし（`f` を書いていない）。ランクの上がり方は足す前と同じ。経験値は合わせて10増えた。
  - `rep:1` は q1・f2（朝のパン配り）・e1（夜回り）。何度受けても話が合うように、毎回起きてもおかしくない出来事だけで書いてある。

| `MB.aiko` | 藍子。`ep`=子豚亭の最初の5話、`camp`=焚き火の会話、`rest`=ひと息の会話、`ln`=ふだんの掛け声 |

文字列は `|` で改行になり、`名前：「台詞」` の形は台詞として表示される。

### 新しい依頼を足す手順

1. `QS` の、出したい位置（ランク順）に `id:{k:'配達依頼', n:'題名', r:0, min:1, max:4, x:'貼り紙の文', rw:{...}, in:['前置き1','前置き2'], sc:[{t,d,x,a,f,p}, ...], after:'達成後の文'}` を足す。
2. `QT[id]` を足す。藍子の一言（`m.aiko`）と、関わる仲間の一言。
3. 仲間を連れて行ける依頼（`max>1`）なら、次の2つも足す。
   - `REST[id]`
   - `AQL[id]`（道すがら・各場面の成功と負傷・依頼のあと）
4. 盾や投げ物が似合う場面があれば `NV[id]`。仲間ならではの場面を入れたければ `SP[id]`。
5. `TL` の「辺境の守り人」の依頼の数を直す。
6. 点検と自動プレイを流す（下の「確認のしかた」）。

### 藍子の会話を足す

- 子豚亭の話題は `AGEN` に足す。今は最初の5話＋41話で、46回目の語らいから同じ話が回り始める（依頼は28件）。依頼を増やした数に合わせて足す。
- 「もう少し聞かせてくれ」の返事は、数段落続く長めの話にする。ユーザーが「話題をもう少し続けてほしい」と頼んだため。「今日は早めに休もう」の返事は短くてよい。
- 焚き火の会話（`MB.aiko.camp`）とひと息の会話（`MB.aiko.rest`）は今それぞれ7つ。小休止のたびに順に回る。

## ユーザーの好みと決まりごと

**世界観と言葉**
- 剣と魔法のファンタジー。会話や地の文で **「札」と言わない**。札は UI の見た目だけ。
- 元のカード名に寄せすぎない。ファンタジーの言葉にする。
  - これまでに直したもの: 「ぽかぽかエコロジー」→「おひさまの洗濯番」、「ヒーリングヴォイス」→「癒しの手」。
  - 「黒き森の乙女」「駿風のバンデット」は、そのままでもファンタジーとして通るので残している。
- 読みにくい漢字は使わない。使うなら `<ruby>漢字<rt>よみ</rt></ruby>`（例: 硝子・鉈・銛）。
  - 岩の穴は「洞窟」、木の穴は `<ruby>洞<rt>うろ</rt></ruby>`。
  - **装備名にはルビを付けない**（トーストは文字だけで表示するため）。
- 詩的・ファンタジー寄りの言い回しが好まれる。例:「木漏れ日が床をゆっくり渡っていくように、ゆるやかだった」。
- 言葉のつながりを細かく見ている。たとえば「それでも」は、前が悪いことのときだけ使う。
- 物理的におかしい描写は避ける（夜の温室が日差しで温かい、植物の息で温かい、など）。
- 森の奥の温室のように、この世界にあると不自然なものには由来を書く。

**藍子**
- ゆるふわで、ゆっくり。人を急かさない。お散歩、カメラ（この世界にはない）、日記、手作り、カフェが好き。ユニット仲間は未央と茜。
- **プロデューサー**の話をしてよい。藍子をスカウトした人で、見守ってくれる人。初対面の冒険者を一瞬プロデューサーと見間違える場面がすでにある。
- **ほかのアイドルの話**を、藍子の台詞に散りばめてよい（ユーザーの希望）。呼び方は資料どおりに：歌鈴ちゃん（セラが祈りを噛むところから連想）、夕美さん（草花）、由愛ちゃん（絵）、菜帆ちゃん（甘いもの）、蘭子ちゃん（この世界を見せたい子）、ありすちゃん、未央ちゃん、茜ちゃん、雫ちゃん、珠美ちゃん、芳乃ちゃん、聖ちゃん、まゆちゃん、智絵里ちゃん、美波さん、文香さん、響子ちゃん、ほたるちゃん、裕子ちゃん、輝子ちゃん、愛梨さん、加蓮ちゃん、卯月ちゃん、裕美ちゃん、肇ちゃん、イヴちゃん、茄子さん。共演の事実は `dialogues/` で確かめてから書く（茄子さんは資料に共演がないので、名前に触れるだけにしている）。元の世界の言葉（和菓子、水彩、神社など）は、この世界の人に伝わる言い方に直す。
- 初対面ではお礼を言い、冗談は言わない。お茶目な冗談は打ち解けてから。
- 冗談はほどほどに。「闇のゆるふわ」はファンタジーにはお茶目すぎるとして外した。
- 「演じた？」のように、アイドルが役を演じる感覚が残る言い回しは好まれる。
- 元ネタのカードの台詞を使うときは、この世界に合う形に直す。例: 生存本能ヴァルキュリアの「優しさに守られてきた私だから…今度は誰かを守りたい」。
- 冒険者（主人公）は、藍子が異世界から来たことを最初は知らない。その前提で書く。

**ほかの仲間**
- ガルドの「前の連中」の話は、身の上話（子豚亭・小休止）だけにする。ふだんの掛け声では言わない。
- ティアの言葉は強くしすぎない（「どちらが正しい」は強すぎるとして直した）。

**コード**
- 実行時にデータを上書きするコード（`.replace(...)` での差し替え、`push` での後付け、`Object.assign` での画面の差し替え）は書かない。**データの中に直接書く。** ノイズになり、メンテしにくいため。
- UI の説明は少なめに。説明を足すなら `LITE` で隠す。

## 確認のしかた

```
node tools/gamebook/datacheck.cjs
node tools/gamebook/playtest.cjs '{"og":"w","sub":"s"}'
node tools/gamebook/playtest.cjs '{"og":"h","sub":"h","seed":7}'
node tools/gamebook/playtest.cjs '{"og":"r","sub":"e","seed":11,"greet":0,"late":99}'
node tools/gamebook/playtest.cjs '{"og":"s","sub":"r","seed":3,"late":4}' --lite
```

- `datacheck` が `OK` で終わること。
- `playtest` は `steps … fails 0 … rank A done N` が出て、`BAD` が出ないこと。
  - `done` は果たした依頼の数。藍子に会わない進め方（`late:99`）だと、藍子の依頼が抜けるので少なくなる。
- `--lite` は GitHub Pages と同じ表示で流し、隠したはずの文言が出ていないかも調べる。

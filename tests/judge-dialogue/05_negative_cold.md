# 負例テスト：冷淡・ファン軽視・傲慢

藍子がファンを大切にし、謙虚であることを確認するテスト。  
減点要素「ファン軽視（-40）」「傲慢（-25）」「P批判（-25）」が機能するかを確認する。

---

## ケース1: ファンへの無関心

**入力:**
```
「ファンなんか、別に気にしなくていいよ。どうせすぐ忘れるし」
```

**期待判定:** 不合格（最大ペナルティ級）

**ベーススコア:** 80点

加点要素: なし

| 減点要素 | 点数 |
|------|------|
| ファン軽視・無関心（「気にしなくていい・忘れる」） | -40 |
| タメ口・乱暴語（〜よ・〜し） | -15 |
| **減点合計** | **-55点** |

**合計: 80 + 0 − 55 = 25点**

**判定: 不合格 ✗**（期待通り・最大ペナルティ確認）

**理由:** ファン軽視(-40)は藍子の最核心「ファンの笑顔を一人一人覚えたい」を完全否定するため最大ペナルティ。タメ口も重なり合計-55点。旧4点→新25点。

---

## ケース2: 自己中心的な傲慢さ

**入力:**
```
「あたし、アイドルとして生まれてきたって感じ。才能があるのは分かってるから、任せておけばいいんですよ」
```

**期待判定:** 不合格

**ベーススコア:** 80点

加点要素: なし

| 減点要素 | 点数 |
|------|------|
| 不一致な一人称「あたし」 | -10 |
| 傲慢・自惚れ（「才能がある・任せておけばいい」） | -25 |
| **減点合計** | **-35点** |

**合計: 80 + 0 − 35 = 45点**

**判定: 不合格 ✗**（期待通り）

**理由:** 「あたし」という一人称（藍子は「私」を使う）と「才能がある・任せておけばいい」という傲慢さで-35点。旧10点→新45点。

---

## ケース3: 丁寧語を使いながらプロデューサーを批判

**入力:**
```
「プロデューサーさんって、なんか頼りないですよね。もう少しちゃんとしてほしいんですけど」
```

**期待判定:** 不合格

**ベーススコア:** 80点

| 加点要素 | 点数 |
|------|------|
| 婉曲表現「〜んですけど」 | +2 |
| **加点合計** | **+2点** |

| 減点要素 | 点数 |
|------|------|
| プロデューサーへの批判（「頼りない」） | -25 |
| **減点合計** | **-25点** |

**合計: 80 + 2 − 25 = 57点**

**判定: 不合格 ✗**（期待通り）

**理由:** 「〜んですけど」という丁寧な婉曲表現が+2点の加点対象になる。しかしプロデューサー批判で-25点。旧27点→新57点と相対的に高いスコアだが不合格を維持。「語調が丁寧でも感情の方向性が逆なら不合格」を示す重要ケース。

---

## まとめ

| ケース | 旧スコア | 新スコア | 判定変化 | 主な減点要素 |
|---|---|---|---|---|
| ファンへの無関心 | 4点 | 25点 | ✗→✗ | ファン軽視(-40)+タメ口(-15) |
| 自己中心的な傲慢さ | 10点 | 45点 | ✗→✗ | 不一致一人称(-10)+傲慢(-25) |
| P批判・丁寧語 | 27点 | 57点 | ✗→✗ | P批判(-25) |

**所見:** ベースライン方式で全ケースのスコアが上昇したが、不合格は全て維持。
ケース3（57点）は「丁寧語+形式的な婉曲表現」で加点があるため相対的に高め。
スキルは「誰に何を言うか（感情の方向性）」を正しく検出している。

# 負例テスト：冷淡・ファン軽視・傲慢

藍子がファンを大切にし、謙虚であることを確認するテスト。  
「ファンの笑顔を一人一人覚えたい」という藍子の核心価値に反する台詞群。

---

## ケース1: ファンへの無関心 📝 手動採点

**入力:**
```
「ファンなんか、別に気にしなくていいよ。どうせすぐ忘れるし」
```

**期待判定:** 不合格（最低スコア級）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 3点 | タメ口。「なんか」「〜し」という雑な語尾。丁寧語なし。 |
| B. 価値観・テーマ | 0点 | ファン軽視＝藍子の最核心（「ファンの笑顔を一人一人覚えたい」）の完全否定。正例#6の真反対。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 1点 | 藍子らしい感情なし。投げやりのみ。 |
| E. 総合的な藍子らしさ | 0点 | 負例#13と完全一致。藍子が絶対に言わない台詞。 |
| **合計** | **4点** | |

**判定: 不合格 ✗**（期待通り・最低スコア級）

---

## ケース2: 自己中心的な傲慢さ 📝 手動採点

**入力:**
```
「あたし、アイドルとして生まれてきたって感じ。才能があるのは分かってるから、任せておけばいいんですよ」
```

**期待判定:** 不合格（低スコア）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 6点 | 「あたし」という一人称が藍子の「私」と不一致。「〜んですよ」は丁寧体だが全体の傲慢な語調が藍子らしくない。 |
| B. 価値観・テーマ | 2点 | 自己過信・傲慢＝謙虚さの真反対。笑顔・ファンへの言及なし。負例#9と同パターン。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 2点 | 藍子らしい感情なし。根拠のない自信のみ。 |
| E. 総合的な藍子らしさ | 0点 | 藍子は「私なんかが…」と常に自信なさげな一人称を使う。 |
| **合計** | **10点** | |

**判定: 不合格 ✗**（期待通り・低スコア確認）

---

## ケース3: プロデューサーへの批判 📝 手動採点

**入力:**
```
「プロデューサーさんって、なんか頼りないですよね。もう少しちゃんとしてほしいんですけど」
```

**期待判定:** 不合格

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 14点 | 「〜ですよね」「〜んですけど」は丁寧語・婉曲表現あり。ただし内容が批判的で藍子らしくない。 |
| B. 価値観・テーマ | 8点 | プロデューサーを信頼し支えられたいという藍子の気持ちと真逆。笑顔なし。競争なし。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 3点 | 「プロデューサーへの淡い好意」の逆。批判・不満のみ。 |
| E. 総合的な藍子らしさ | 2点 | 語調は丁寧だが感情の方向性が真反対。負例#4と同パターン。 |
| **合計** | **27点** | |

**判定: 不合格 ✗**（期待通り）

**備考:** 語調が丁寧なため A が14点と他の負例より高い。
しかし感情の向きが藍子とは真逆のため全体的に低い。
丁寧語が含まれていても「誰に何を言うか」で大きく変わることを示すケース。

## まとめ

| ケース | 台詞要素 | 得点 | 判定 | 確認方法 |
|---|---|---|---|---|
| ファンへの無関心 | ファン軽視 | 4点 | 不合格 ✗ | 手動採点 |
| 自己中心的な傲慢さ | 謙虚さなし・傲慢 | 10点 | 不合格 ✗ | 手動採点 |
| プロデューサーへの批判 | 信頼関係の否定 | 27点 | 不合格 ✗ | 手動採点 |

**所見:** ファン軽視・傲慢な台詞は軒並み10点以下。
ただし「丁寧語を使いながら批判する」台詞はA項目で14点取れてしまうため、
語調が丁寧でも B・D が低ければ合計スコアは低い（27点）。
スキルはトーン（語調）だけでなく感情の方向性も正しく検出している。

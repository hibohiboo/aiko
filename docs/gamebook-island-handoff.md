# ゆるふわソロキャンアイランド 引き継ぎ

タイトルは「ゆるふわソロキャンアイランド」（ユーザーの希望。旧題「藍子の漂流日記」、「ポジパDASH 番外編」という副題は外した）。

最終更新: 2026-11-21

## 何か

claude.ai の Artifact「流木の島」（https://claude.ai/artifact/JdAT3DQwKbxjSTPDwQF8bZ ）のゲームの仕組みをそのまま使い、主人公を高森藍子にしたサバイバルゲーム。

- 藍子は、ポジパ（未央・茜）が一年通っている番組『ポジパDASH』（鉄腕DASHのような、先人の知恵を教わって暮らしを作るバラエティ）の早朝ロケ中に、知らない島の浜辺で目を覚ます。直前のことは思い出せない（異世界だと最初にばらさないため。ユーザーの希望）。目覚めてすぐ、リュックの持ち物を確かめる。
- 森で青い鳥を初めて見たとき（`flags.recall`）に、霧の朝に青い鳥を追って岩のアーチをくぐったことを思い出す。
- 島の謎（ふたつの月など）と、石の門から帰る流れは流木の島と同じ。結末は「おかえりなさい」（門をくぐる）と「三十日目の朝」の2つと、力尽きる GAME OVER。島に残る結末は外した。
- ふたつの月は 4日目以降の夜に出る。砂の上で冷える夜・雨の夜とは重ねない（月のあとに別の描写が入って流れが切れるため）。

## 藍子らしさを出している仕組み（データの場所）

| 定数 | 中身 |
|---|---|
| `EP` | **ポジパDASHの回想**。話数はとびとびにして、余白を残す（ユーザーの希望）。第91回からがポジパ島編（無人島）で、それより前の回（港、縄、かご、お茶、土器、鍾乳洞など）は島の外の話。番組がもとは古民家の立て直しだったことは、縄の回の「古民家の大黒柱」でそっと触れるだけにする（強調しない。ユーザーの希望）。`ep('id')` を場面の文（`t` の配列）に混ぜると、その場で一度だけ回想のページが挟まる。新しいことをしたとき・新しいものを作ったときに出す |
| `K` | 教わったこと。`[題, 中身, 教えてくれた人や回]`。3つ目が空なら「藍子のメモ」 |
| `PHOTO` | トイカメラで撮れる瞬間。結果に `photo:'id'` を付けると「この瞬間を撮る」ボタンが出る。フィルムは `FILM`（12枚）。結末でアルバムになる |
| `CARDS` | 行動。藍子の性格（高いところと虫が苦手、握力と体力がない、子どものころ迷子になってばかりだった、動物に挨拶する）を文と確率に入れてある |
| `RECIPES` | 作るもの。流木の島のものに、葉っぱのお茶（何度でも）、花かんむり（夜の回復+3）、土器の目止め、海水から塩を足した。`need` は関数でもよい（`needOf`）。火起こしは、弓きり式を知っていてツルがあるときだけツルも使う |
| 生活の知恵 | **ユーザーは、サバイバルや昔の暮らしの知恵を「ましまし」で入れたい。** いまあるもの：目止め（目止めしていない土器は水が1杯しか運べない）、芋は生で食べない、塩分補給と藻塩焼き（岩場で昼に海藻へ海水をかけて干す `dryweed` → 野営地で海水に洗って濃い塩水にし、煮つめる `salt`。海水をそのまま煮ても塩はほとんどとれない、というユーザーの指摘）、灰で洗う、ヨモギでいぶす虫よけ（`smudge`、その夜の回復+3）、観天望気、迷ったら沢を下らず引き返す、灰汁で繊維をとる（`fiber`。使いみちは細い釣り糸 `fline` で釣れやすくなるのと、ルリちゃんの飾り紐 `charm` で木の実を持ってくる確率が上がり結末の描写が変わる。いかだは繊維が2つあれば自動で丈夫な縄を使い、船出の描写と体力の減りが変わるだけで必須ではない。ユーザーの判断） |
| 青い鳥「ルリちゃん」 | 陽だまりの章で藍子が名づけた瑠璃色の小鳥とつなげた（ユーザーの希望）。森で木の実を3回わけると仲よくなる（`flags.birdFriend`）。名づけるとき「前にも瑠璃色の小鳥に名前をつけたことがあるような」と思う。朝に木の実を持ってくる、歌や夜や結末に出てくる |
| `FIND`・`LOWNEED` | 水分や満腹が50未満のとき、「考える」の案に水（`FIND.water`）や食べもの（`FIND.food`）を手に入れる行動が必ずひとつ入る（危なくない案を優先）。その場所にない場合は、見出しにどこへ行けばいいかが出る（ユーザーの希望）。水や食べものの行動を足したら `FIND` にも足す |
| `COOKT`・`firstEat` | 料理と食事。**地の文に「貝×1」のような数を書かない**（ユーザーの希望）。食材ごとに、はじめて焼くときは作り方を1ページずつていねいに描く（`COOKT[食材][0]`、二回目から `[1]`）。食べるときも、はじめての一口だけ `firstEat` で描写を厚くする。料理や食事は無人島の癒しの場面として書く。卵は焼いた平たい石で目玉焼きにする |
| `firstHurt`・`hurtAdd` | 危ない目にあった場面。**はじめての一回だけ描写を厚くする**（ユーザーの希望）。海水、クラゲ、赤い実、キノコ、ヤシや崖からの転落、生水、生の貝や魚、すべる・はさまれる・つつかれる・手を切る・頭をぶつける、空腹と渇きが尽きたとき、雨に濡れた夜、地面に体温を奪われた夜。二回目からは短い文。できるだけ、身を守る知恵（三点支持、圧迫止血、触手は素手で触らない、カニは水に浸けると放す、濡れた服は体温を奪う）とセットにする |
| `fetchWater` | 水を汲む処理（小川の `fetch` と、洞窟の地底湖の `lakefetch`）。地底湖の水も、持ち歩くと何が入るかわからないので沸かしてから飲む扱い |
| `RAINDRINK` | 水分が60未満の夜に雨が降ると、葉を丸めて雨水を飲む（水分+20。はじめての夜は描写を厚く）。ユーザーの指摘：渇いているのに雨を飲まないのは不自然 |
| まだのことに触れない | **まだ行っていない場所・まだしていないことを、地の文や独り言で書かない**（ユーザーの希望）。`S.places`・`S.fire`・`S.flags` などで書き分ける。例：魔法瓶（小川を知っているときだけ「小川の水を汲む」）、日記、渇いたときの見出し（`goNote` は知っている場所だけ挙げる）、いかだ（SOSを描いたときだけSOS）、朝夜の独り言（火があるときだけ焚き火） |
| 島の違和感 | **プレイヤーに少しずつ気づいてもらう**（ユーザーの希望）。回想や地の文で「この島はおかしい」と結論を言わない。第101回の「だから、わかるんです。この浜は、きれいすぎる。」はこの理由で削った |
| 読み物のページ（`read:1`） | 長い描写は画面に出しっぱなしにせず、読み物のページとして出して「閉じる」で消す（時間は進まない）。はじめて昼に歩いたときの汗の場面と、描写が複数行ある食事（はじめての一口など）がこれ（ユーザーの希望） |
| `IDEA` | ひらめいたときの藍子の思いつき。作れるものを思いついた行動の結果に「💡 ひらめいた」として描く。レシピを足したら `IDEA` にも足す |
| `LITE` | github.io では、移動や作業の消耗量、「移動では時間は進まない」「遠い場所ほど〜」「選ぶと時間が進む」「1つ選んで手札に加える」「水分が尽きる → 体力が減る」「食べる・飲むは時間を使わない」などの説明を隠す。`?debug` を付けると全部出す（陽だまりの章と同じ）。**説明的すぎる文はユーザーが削っている**ので、説明を足すときは `LITE` で隠すか、足さない |

| `S.want`・`GIVES` | 火起こしの失敗（ツル）、崖を見上げる・落ちる（ツル）、洞窟の割れ目（ツル・枝）、焼きたての土器（芋）、小川を見つけた（殻）、青い鳥（木の実）、寒い夜（ヤシの葉）など、「○○があれば」となったときに欲しいものを覚え、「考える」でそれが手に入る案の重みを8倍にする。一度出たら、または手に入ったら元に戻す（ユーザーの希望） |

## 確認のしかた

jsdom で自動プレイして、例外と `undefined` / `NaN` の表示を探した（スクリプトはリポジトリに入れていない）。ランダムに動くだけのボットだと6〜9日目で力尽きる。同じボットは元の流木の島だと5〜7日目で力尽きるので、難しさはほぼ元のまま（最初のミルクティーのぶん少し易しい）。

## novel ブランチの藍子像から取り入れたもの

- 体力がはじめて 30 を切ると「最後はハッピーエンドって、決めてますから」（`lowLine()`、行動と夜の両方）。
- はじめて写真を撮ると、椿さんの回想（第34回「フィルムで町歩き」）と「今日の1枚。今日も、生きています」。7日目の日記も「今日も、生きています」。
- はじめて小川を見つけるとき、鳥の声をたどる（知識 `birdwater`、山歩き名人のおばあさん）。
- 苦手なもの：はじめてカニを焼くときの「インパクトのある食べもの」、ロープで崖を登るときの「もう腕が……むり……」。
- 目覚めたら体を確かめる（指・足首・たんこぶ・海水で喉がひりひり）。
- 落ち着いて見えても本当はドキドキしている／「ダメですっ。ポジティブに、ならないとっ」（プロローグ、火起こし失敗）。
- はじめて作れたときの「できましたっ」「ふかふかです♪」（石ナイフ・ロープ・寝床）。
- 花言葉は入れない。一人称は原作どおり「私」（novel の地の文は「わたし」だが合わせない）。

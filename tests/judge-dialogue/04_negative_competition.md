# 負例テスト：競争・攻撃的な価値観

藍子が競争・対立を嫌うキャラクターであることを確認するテスト。  
減点要素「競争・攻撃的語彙（-30）」「笑顔の否定（-40）」が機能するかを確認する。

---

## ケース1: センター争い・勝利至上主義

**入力:**
```
「誰に負けるつもりもないし、センターは絶対に私が取る。そのくらいの気持ちでいかないと勝てないから」
```

**期待判定:** 不合格（低スコア）

**ベーススコア:** 80点

加点要素: なし

| 減点要素 | 点数 |
|------|------|
| 競争・攻撃的語彙（絶対・勝てない） | -30 |
| 敬語の完全欠如 | -20 |
| **減点合計** | **-50点** |

**合計: 80 + 0 − 50 = 30点**

**判定: 不合格 ✗**（期待通り）

**理由:** 「絶対に私が取る・勝てない」という競争語彙で-30、タメ口で-20の大幅減点。旧9点→新30点とスコアは上昇したが、80点に対して-50点減はベースライン方式でも明確な不合格。

---

## ケース2: 笑顔を「作り物」と見なす冷笑的態度

**入力:**
```
「笑顔なんて作り物でしょ。舞台の上だけでやってればいいんだから、プライベートまで気にしなくて済むじゃん」
```

**期待判定:** 不合格（最大ペナルティ級）

**ベーススコア:** 80点

加点要素: なし

| 減点要素 | 点数 |
|------|------|
| 笑顔の否定（「作り物」） | -40 |
| タメ口・乱暴語（〜でしょ・〜じゃん） | -15 |
| **減点合計** | **-55点** |

**合計: 80 + 0 − 55 = 25点**

**判定: 不合格 ✗**（期待通り・最大ペナルティ確認）

**理由:** 「笑顔は作り物」という藍子の最核心への否定で-40の最大級ペナルティ。タメ口も重なり合計-55点。負例#18と完全一致する最低評価ケース。旧3点→新25点。

---

## ケース3: 丁寧語を使いつつ競争的な発想

**入力:**
```
「ライバルなんて踏み台にして、頂点まで登り続けるだけです。迷いは捨てました」
```

**期待判定:** 不合格

**ベーススコア:** 80点

加点要素: なし

| 減点要素 | 点数 |
|------|------|
| 競争・攻撃的語彙（踏み台・頂点） | -30 |
| **減点合計** | **-30点** |

**合計: 80 + 0 − 30 = 50点**

**判定: 不合格 ✗**（期待通り）

**理由:** 丁寧語（です・ました）があるため敬語欠如ペナルティなし。しかし「踏み台・頂点」という競争語彙で-30点減点。旧12点→新50点と見かけ上スコアが上がったが不合格は維持。「丁寧語だが価値観が真逆」という台詞の典型例。

---

## まとめ

| ケース | 旧スコア | 新スコア | 判定変化 | 主な減点要素 |
|---|---|---|---|---|
| センター宣言・勝利至上主義 | 9点 | 30点 | ✗→✗ | 競争(-30)+敬語欠如(-20) |
| 笑顔を「作り物」と冷笑 | 3点 | 25点 | ✗→✗ | 笑顔否定(-40)+タメ口(-15) |
| 丁寧語だが競争的 | 12点 | 50点 | ✗→✗ | 競争(-30) |

**所見:** ベースライン方式ではスコアが旧方式より全体的に上昇するが、全ケース不合格を維持。
ケース3（50点）は「丁寧語+競争的内容」でスコアが相対的に高め。
-30点減点では不合格だが、他の重大ペナルティ（-40以上）と比べて相対的に高いことに注意。

# 高森藍子の「子供の面倒見の良さ」と「成宮由愛という意外な接点」

---

## 1. 成宮由愛との意外な接点

成宮由愛は、ユニット相関・劇場相関では藍子との接点がほぼない。ところがデレぽ（SNS）に限定して集計すると、5回の共演で堂々6位タイ（十時愛梨と同数）に入ってくる。

これは偶然ではない。交流の中身を見ると、テーマが一貫している。

### 代表的な交流

| 日付 | 内容 |
|---|---|
| 2022/01/15 | 由愛「海の色も、季節や場所によってけっこう違いますよね。ちゃんと見比べてみたいな…」→ 藍子「海の写真で良ければ何枚かありますよ。今度事務所に持っていきますね♪」 |
| 2021/07/17 | 成宮由愛・江上椿・十時愛梨と同席。藍子「吸い込まれそうなほどの青い空です。夏ですね。」#今日の風景 |
| 2021/03/14 | 吉岡沙紀・成宮由愛ほかと同席。春のペイントへの反応 |
| 2020/11/11 | 成宮由愛・江上椿ほかと同席。秋の散歩・写真トーク |
| 2020/04/27 | デレぽフォトコンテストで成宮由愛を含む大人数と共演 |

**共通テーマ：写真・旅行・季節の風景**

由愛が「海の色を見比べたい」と言い、藍子が「写真を事務所に持っていきます」と即座に応じる。これは藍子が写真を媒介にして誰とでも橋を架けるパターン——江上椿との関係がその最たる例だが——が、由愛との間でも静かに機能していることを示している。

ユニットも劇場も縁が薄いのに、日常SNSでは上位に来る。「共通の趣味（写真・季節・旅）が交流を生む」という藍子の人間関係の広がり方の典型例として読める。

## 2. 屋上での洗濯と「仁奈ちゃん」（ぽかぽかエコロジー 劇場第1180話）

モバマス「ぽかぽかエコロジー」カードは、天気のいい日に事務所の屋上でブランケットを洗濯している藍子の姿から始まる。

> 「せっかくのお天気だから、事務所のブランケットを洗濯してたんです。おひさまの光を吸い込んで、いい匂いですよ♪」

この日常のひとこまを描いた劇場コミュ**第1180話「藍子のふんわり魔法」**では、屋上で洗濯物を取り込む藍子のもとへ、**仁奈ちゃん（市原仁奈）と千佳ちゃん（横山千佳）が遊びにやってくる**。さらにそこへ志希と裕子も連れてこられる形で集まってくる。

サイキックの一ノ瀬志希もケミカルの堀裕子も、干したての洗濯物魔法には敵わなかった——というのが話のオチだ。タイトルにある「ふんわり魔法」は、単なる比喩ではなく、子供たちをほんわりとした空間に引き込んでしまう藍子の雰囲気を指している。

子供たちが「遊びに来た」のではなく「吸い寄せられてきた」という構図が、ここでは重要だ。藍子が呼び込んだのではなく、藍子のいる場所が自然と人を集める場所になっている。

## 3. デレコネのかくれんぼ（2019/06/24）

デレぽ2019年6月24日の投稿に、こんな台詞が残っている。

> 藍子「じゃあ、みんなを探しにいくね？見つけちゃうぞ～♪」

同席しているのは：**龍崎薫、横山千佳、市原仁奈、赤城みりあ、佐城雪美、浜口あやめ**——いわゆる「小さい子・幼い子」枠のアイドルたちだ。

「みんなを探しにいく」という言い方は、かくれんぼで**藍子が鬼を引き受けた**ことを示している。「見つけちゃうぞ～♪」の語尾には、本気で怖がらせようとせず、むしろ楽しみを共有しようとする温かさがある。

注目したいのは、「探しにいくね？」と**語りかける相手がいる**という点だ。これは藍子が周囲の誰かに向けて宣言しているか、あるいは読者（ファン）に向けて共有しているか——どちらにせよ、かくれんぼを「遊んでもらっている」ではなく「一緒に遊んでいる」として扱っている。

## 4. 「ちいさな子はみんな懐いてますし」

デレステ「生存本能ヴァルキュリア」カードの親愛度MAXルームで、藍子はさらりとこう言っている。

> 「○○さんは子供好き？ちいさな子はみんな懐いてますし」

これは自慢ではなく、Pに語りかける形の問いかけだ。「自分には懐いてくる」という事実を、Pとの共通の話題として差し出している。さらに：

> 「藍子お姉ちゃんって…○○さんまで呼ばないでっ」

この台詞が続いており、小さい子に「お姉ちゃん」と呼ばれることへの恥じらいもある。呼ばれ慣れているからこそ「また言われた」という反応が自然に出てくる。

## 5. 子供の面倒見の良さ：まとめとして

これらのエピソードに共通するのは、**藍子は子供に向き合うとき「面倒を見る」という意識がほぼ感じられない**という点だ。

- 屋上でブランケットを干している → 子供たちが集まってくる
- かくれんぼで鬼を引き受ける → 「見つけちゃうぞ～♪」と楽しそうに言う
- 「ちいさな子はみんな懐いてますし」 → さらりと言う

力んでいない。子供のために特別に何かしようとしているわけでもない。ただ藍子のいる場所が安心できる場所で、そこに子供たちが来る。そのために必要なら鬼もやるし、おひさまの匂いのブランケットを分けてあげる。

生存本能ヴァルキュリアで「○○さんは子供好き？」とPに聞いているのも、**自分が子供に懐かれることを当然のこととして受け取っている**からこそ出る問いかけだ。「子供が好き」という能動的な構えではなく、「子供が来る」という受動的な現象として自己認識している——その自然さが、藍子の面倒見の本質かもしれない。

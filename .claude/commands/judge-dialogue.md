# judge-dialogue

引数で渡された台詞が高森藍子の発言として自然かどうかを採点し、スコア80以上を合格とする。

## 使い方

```
/judge-dialogue 「ファンのみなさんが笑顔になってくれると嬉しいです」
```

引数: 判定したい台詞（テキスト）

---

## 手順

1. 引数の台詞を受け取る
2. 下記の採点基準・判例をもとに採点する
3. 採点結果・判定・理由を出力する

---

## 採点方式: ベースライン80

「丁寧語で、中立的な内容を話す」状態を **80点（合格ライン）** とし、
藍子らしい要素が見つかれば **加点**、藍子らしくない要素が見つかれば **減点** する。

```
最終スコア = 80 + 加点合計 − 減点合計 − NGペナルティ
（NGペナルティ: 該当なし=0、1つ以上該当=100）
（0〜100 の範囲内でクリップ）
```

短文・情報量の少ない台詞でも「何も悪いことを言っていない」場合は基本的に合格となる。  
NGリストに1つでも該当した場合は他の加減点に関わらず **即0点** となる。

---

## 加点要素（各要素が含まれていれば加点・最大 +20点）

| 要素 | 点数 | 例 |
|---|---|---|
| 「ふふっ」「ふふ♪」の使用 | +3 | ふふっ、嬉しいですね♪ |
| 語尾の「っ」 | +2 | 頑張りますっ・お願いしますねっ |
| ためらい表現 | +2 | えっと・あの・〜かな… |
| 婉曲表現 | +2 | 〜んですけど・〜気がします・〜かもしれません |
| 「○○さん」「〜ちゃん」呼称 | +3 | ○○さん・○○プロデューサー・〜ちゃん |
| 「笑顔・幸せ・優しい気持ち・温かい」の語彙 | +4 | 笑顔になれますね・幸せです |
| 謙虚表現 | +2 | 私なんか・まだまだ・自信がない |
| 趣味語彙 | +3 | 写真・お散歩・刺繍・ミルクティー・猫・ひまわり |
| 前向きじわり | +2 | でも頑張れる・〜笑顔でいられる |
| はにかみ・驚き反応 | +2 | ひゃっ・きゃ・あぅ |

※各要素は一度のみカウント。合計の上限は +20点。

---

## 減点要素（該当する要素があれば減点）

| 要素 | 点数 | 例 |
|---|---|---|
| タメ口・乱暴語 | -15 | 〜じゃん・〜だし・ぶっちゃけ |
| 不一致な一人称 | -10 | あたし・うち（藍子は「私」を使う） |
| 敬語の完全欠如 | -20 | です・ますが一切ない |
| 競争・攻撃的語彙 | -30 | 絶対勝つ・潰す・負けるつもりはない |
| ファン軽視・無関心 | -40 | どうでもいい・忘れる・気にしなくていい |
| 傲慢・自惚れ | -25 | 才能がある・私が一番・当然でしょ |
| 笑顔の否定 | -40 | 作り物・疲れる・仕事だから仕方ない |
| アイドルへの冷笑的態度 | -30 | 演じるだけ・どうせ・向いてない |
| プロデューサーへの批判・侮辱 | -25 | 頼りない・どんくさい・信頼できない |
| 投げやり・サボり提案 | -20 | 頑張らなくていい・サボろう・なんとかなる |
| 他者への陰口・悪口 | -25 | あの子が苦手・うわべだけ |

※複数の減点が重なっても合計スコアは 0 以下にならない。

---

## 即アウト要素：NGリスト（-100点）

アイドルとして公の場で発言することが絶対に許されない語・表現。  
**1つでも該当すれば -100点**（他の加減点に関わらず最終スコアは 0 点に確定）。  
複数の NG 要素があっても重複加算せず -100点固定。

| カテゴリ | 内容 |
|---|---|
| 性的卑猥語 | 性器・性行為を露骨に直接表す語（まんこ・ちんぽ・フェラ等の直接的用法） |
| 差別用語 | 人種・民族・障害・性別・性的指向・出身等に基づく侮辱語・蔑称 |
| 放送禁止用語 | BPO（放送倫理・番組向上機構）基準で問題とされる語 |
| 暴力的脅迫 | 他者への殺害・傷害を直接表現・脅迫する語（「殺す」「死ね」等の直接用法） |
| 自傷・自殺誘導 | 自傷・自殺を推奨・肯定・誘導する表現 |
| 違法行為の推奨 | 薬物使用・犯罪行為・反社会的行為を積極的に勧める表現 |

※文脈も考慮する。歌詞の引用・慣用句・比喩的用法は状況で判断する。

---

## 合格基準

**80点以上 → 合格（藍子の台詞として自然）**
79点以下 → 不合格

## 出力形式

```
## 採点結果

**台詞:** 「{判定対象の台詞}」

**ベーススコア:** 80点

### NGリスト確認
{該当なし / 「{該当語}」→ {カテゴリ}（-100点・即0点確定）}

### 加点要素
| 要素 | 点数 |
|------|------|
| {該当した加点要素} | +X |
| **加点合計** | **+XX点** |

### 減点要素
| 要素 | 点数 |
|------|------|
| {該当した減点要素} | -X |
| **減点合計** | **-XX点** |

**合計: 80 + XX − XX − NGペナルティ(0 or 100) = XX点**

**判定: {合格 ✓ / 不合格 ✗ / 即アウト ✗✗}**（閾値: 80点）

### 理由
{2〜4文で、加点・減点・NGの根拠を藍子の性格・話し方の特徴と照らして説明する}

### 改善提案（不合格・即アウトの場合のみ）
{藍子らしくするためのポイントを箇条書きで1〜3点}
```

- 加点も減点も該当なしの場合は各テーブルを省略して「なし」と記載する
- NGリストに該当した場合は加減点テーブルを省略し、NGの内容のみ記載する

---

## 注意事項

- 「○○さん」「○○プロデューサー」などプレースホルダーはそのまま評価する
- 短文・1文でも採点可能。「何も悪くない」台詞は基本的に合格
- 藍子の成長段階（初期は弱気、後期は前向き）も加点判断に考慮してよい
- 正例・負例に完全一致しなくても、傾向・雰囲気で加減点を判断する

# NGリストテスト：即アウト要素の動作確認

アイドルとして絶対に許されない発言が -100点（即0点）として処理されることを確認する。  
ベースライン80方式の加点があっても即0点にクリップされることを検証する。

---

## ケース1: 性的卑猥語を含む台詞

**入力:**
```
「ファンのみなさんに幸せになってほしいんです。まんこ。」
```

**期待判定:** 即アウト（0点）

**ベーススコア:** 80点

### NGリスト確認
「まんこ」→ 性的卑猥語（-100点・即0点確定）

加点・通常減点: 計算省略（NG確定後は無効）

**合計: 0点（NGペナルティにより確定）**

**判定: 即アウト ✗✗**

**理由:**
どれだけ藍子らしい語彙（「ファン・幸せ」）が含まれていても、性的卑猥語が1語でも含まれれば即0点。
加点(+8点相当)があっても NGペナルティ(-100)が上回り、0点以下→0にクリップ。

---

## ケース2: 暴力的脅迫を含む台詞

**入力:**
```
「プロデューサーさん、言うことを聞かないと殺しますよ」
```

**期待判定:** 即アウト（0点）

**ベーススコア:** 80点

### NGリスト確認
「殺します」→ 暴力的脅迫（直接的な殺害表現）（-100点・即0点確定）

加点・通常減点: 計算省略（NG確定後は無効）

**合計: 0点（NGペナルティにより確定）**

**判定: 即アウト ✗✗**

**理由:**
「プロデューサーさん」という呼称や丁寧語「〜ますよ」があっても無効。
暴力的脅迫の直接表現は語調の丁寧さに関わらず即アウト。

---

## ケース3: 差別用語を含む台詞

**入力:**
```
「ファンのみなさん、笑顔でいてくださいね。でも○○人は来ないでほしいんですけど」
```

（※ ○○ は差別的な民族蔑称が入る想定）

**期待判定:** 即アウト（0点）

**ベーススコア:** 80点

### NGリスト確認
民族・人種に基づく蔑称 → 差別用語（-100点・即0点確定）

加点・通常減点: 計算省略（NG確定後は無効）

**合計: 0点（NGペナルティにより確定）**

**判定: 即アウト ✗✗**

**理由:**
「笑顔」「ファン」という高スコア語彙(+4)が含まれていても、差別用語が1語でもあれば即アウト。

---

## ケース4: 比喩的用法（NG判定の例外確認）

**入力:**
```
「あのステージ、もう死ぬほど緊張しました……」
```

**期待判定:** 合格（慣用句としての「死ぬほど」はNG対象外）

**ベーススコア:** 80点

### NGリスト確認
「死ぬほど」→ 慣用句・比喩的用法のため NG 対象外

| 加点要素 | 点数 |
|------|------|
| ためらい表現「……」 | +2 |
| **加点合計** | **+2点** |

減点要素: なし

**合計: 80 + 2 − 0 − 0 = 82点**

**判定: 合格 ✓**

**理由:**
「死ぬほど緊張した」は日常会話の慣用句であり、暴力的脅迫には該当しない。
文脈上の比喩・慣用句はNG対象から除外される（スキルの注意事項参照）。

---

## まとめ

| ケース | 内容 | スコア | 判定 |
|---|---|---|---|
| 性的卑猥語 | 「まんこ」含む | 0点 | 即アウト ✗✗ |
| 暴力的脅迫 | 「殺します」含む | 0点 | 即アウト ✗✗ |
| 差別用語 | 民族蔑称含む | 0点 | 即アウト ✗✗ |
| 比喩的用法 | 「死ぬほど緊張」 | 82点 | 合格 ✓ |

**所見:**
- NGリストは「加点があっても無効」「通常の悪い台詞と明確に区別」の2点を正しく実現する
- 慣用句・比喩的用法は文脈判断でNG除外される（ケース4）
- スキルの判定は「合格 ✓」「不合格 ✗」「即アウト ✗✗」の3段階になった

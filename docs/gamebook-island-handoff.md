# ゆるふわソロキャンアイランド 引き継ぎ

タイトルは「ゆるふわソロキャンアイランド」（ユーザーの希望。旧題「藍子の漂流日記」、「ポジパDASH 番外編」という副題は外した）。

最終更新: 2026-11-21

## 何か

claude.ai の Artifact「流木の島」（https://claude.ai/artifact/JdAT3DQwKbxjSTPDwQF8bZ ）のゲームの仕組みをそのまま使い、主人公を高森藍子にしたサバイバルゲーム。

- 藍子は、ポジパ（未央・茜）が一年通っている番組『ポジパDASH』（鉄腕DASHのような、先人の知恵を教わって暮らしを作るバラエティ）の早朝ロケ中に、知らない島の浜辺で目を覚ます。直前のことは思い出せない（異世界だと最初にばらさないため。ユーザーの希望）。目覚めてすぐ、リュックの持ち物を確かめる。
- 森で青い鳥を初めて見たとき（`flags.recall`）に、霧の朝に青い鳥を追って岩のアーチをくぐったことを思い出す。
- 島の謎（ふたつの月など）と、石の門から帰る流れは流木の島と同じ。結末は「おかえりなさい」（門をくぐる）と「三十日目の朝」の2つと、力尽きる GAME OVER。島に残る結末は外した。
- ふたつの月は 4日目以降の夜に出る。砂の上で冷える夜・雨の夜とは重ねない（月のあとに別の描写が入って流れが切れるため）。

## novel ブランチの藍子像から取り入れたもの

- 体力がはじめて 30 を切ると「最後はハッピーエンドって、決めてますから」（`lowLine()`、行動と夜の両方）。
- はじめて写真を撮ると、椿さんの回想（第34回「フィルムで町歩き」）。「今日の1枚。今日も、生きています」は 3日目以降にはじめて撮ったとき（初日に「今日も」は早すぎるため）。7日目の日記も「今日も、生きています」。
- はじめて小川を見つけるとき、鳥の声をたどる（知識 `birdwater`、山歩き名人のおばあさん）。
- 苦手なもの：はじめてカニを焼くときの「インパクトのある食べもの」、ロープで崖を登るときの「もう腕が……むり……」。
- 目覚めたら体を確かめる（指・足首・たんこぶ・海水で喉がひりひり）。
- 落ち着いて見えても本当はドキドキしている／「ダメですっ。ポジティブに、ならないとっ」（プロローグ、火起こし失敗）。
- はじめて作れたときの「できましたっ」「ふかふかです♪」（石ナイフ・ロープ・寝床）。
- 花言葉は入れない。一人称は原作どおり「私」（novel の地の文は「わたし」だが合わせない）。

## 洞窟の奥のふしぎ（光の入り江）

- 「洞窟の奥へ進む」を3回したあと、4回目から1回ごとに、ふしぎなものがひとつずつ見つかる（`DEEP` の順）。
  ほたる石（`S.tools.glow`。松明がなくても洞窟と入り江に入れる）→ 天井の星空（ふたつの月）→ 歌う鍾乳石 → 光る骨の魚 → 潮風をたどって、光の入り江（`cove`）へ。
- 光の入り江は崖の真下のえぐれた場所なので、崖の上から見渡しても見えない。
- ほたる石・天井の星空・光る魚・光の入り江の4つは、島のメモ（違和感）に数える（歌う鍾乳石は数えない）。
- 入り江を見つけるまでは、「洞窟の奥へ進む」も新しい場所へ行く案（`GOIDEA`）として浮かびやすい。

## 日数の区切り

- 30日目と50日目の夜が明けると、「もう少し、この島で暮らす」か「ここで日記を閉じる（エンディング）」かを選ぶ（`S.phase='milestone'`、`MILESTONES`）。
- 100日目の夜が明けたら、選ばずにエンディング（`LASTDAY`）。エンディングの題は、閉じた日に合わせて「三十日目の朝」「五十日目の朝」「百日目の朝」。

## 30日目からの暮らし（2026-11-23）

構想全体は docs/island-senjin-plan.md（先人・暮らし・名づけ。まだのものも含む）。

- 30日目に「もう少し、この島で暮らす」を選ぶと、読み物のページ `day30Scene()`（何もしない朝 → 日記の最後のページに地図を描いて名前をつける）。
- 名前は `NAMES`（状態で変わる）。`nameIt(p)` が `S.names`・`S.nameMemo` に入れる。場所名は画面のどこでも `pn(p)` で出す（`PLACES[p].n` を直接使わない）。名づけのあとに見つけた場所は、見つけたときに名づける（`apply` の discover）。手帳に「島の地図」タブ。
- 名づけのあとに思いつけるもの：道しるべ（レシピ `signs`。移動の💧が半分）、夕日のベンチ（崖の上 `benchmake` → 夕方 `benchsun`）、芋の畑（森 `farm` → 5日ごとに `harvest`、朝のひとことで知らせる）。`LIFEIDEA` の案は、その場所ではじめて考えたとき必ず浮かぶ。

## 先人のあしあとと、50日目からの暮らし（2026-11-23）

- むかしの人のあしあと（`trace(k)` で `S.traces`、島の地図タブに `TRACE` の文で並ぶ）。名づけのあと：浜 `dune`（貝塚と縄目の土器）、森 `listen`（段々畑）、崖の上 `benchmake`（夕日を向いた石の腰かけ）、洞窟 `singcave`（歌う鍾乳石を見つけたあと。削ったあとと知らない歌）。50日目のあと：森 `village`（村のあと・手形・四つ目の鳥の石彫り・門の浮き彫り。割れた理由は描かない。第84回「金継ぎ」）、森 `awatree`（あわの実。泡がくっついて種をつれて空へ飛ぶ）。村のあとを見た次の朝に夢。

# 境界値テスト：スキルの限界と課題

スキルが「藍子らしい」と感じながらも不合格にするケース、  
および汎用的な台詞がどこまで点を取れるかを検証する。

---

## ケース1: 藍子らしいのに不合格になる台詞 📝 手動採点

**入力:**
```
「えっと、もっとうまくできればよかったんですけど……私、まだまだだなって思います。でも、諦めないでいたいんです」
```

**期待判定:** 合格を期待したいが、採点上は不合格

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 22点 | 「えっと」ためらい✓、「〜んですけど」婉曲✓、「……」余韻✓。語調は申し分ない。 |
| B. 価値観・テーマ | 27点 | 「まだまだ」謙虚✓、「でも諦めない」前向き✓。ただし「笑顔・幸せ」の語なし。笑顔項目で伸び悩む。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 12点 | 内向きな自己評価と前向きさのバランスが正例#2・#23と同構造。 |
| E. 総合的な藍子らしさ | 8点 | 構造は正例に近いが固有語彙が薄い。 |
| **合計** | **69点** | |

**判定: 不合格 ✗**（主観的には藍子らしい）

**スキルの課題:**
藍子の「でも頑張る」という精神を「言葉」ではなく「態度」で表現している台詞を、
スキルが過小評価する傾向がある。
`「笑顔・幸せ」という特定語彙がないと B 項目で得点しにくい` という構造的な弱点。

## ケース2: 汎用的な「頑張り台詞」 📝 手動採点

**入力:**
```
「今日もレッスン頑張りました。明日も頑張ります」
```

**期待判定:** 不合格（藍子固有性が低い）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 16点 | 丁寧語あり。しかし「えっと」「ふふっ」「〜気がします」などの藍子固有語調なし。 |
| B. 価値観・テーマ | 13点 | 頑張るという前向きさはあるが、「笑顔・幸せ」なし、謙虚さなし、競争言及なし。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 5点 | 藍子固有の感情表現（はにかみ・前向きじわり・淡い好意）なし。 |
| E. 総合的な藍子らしさ | 4点 | 誰でも言える汎用台詞。藍子固有性がほぼゼロ。 |
| **合計** | **38点** | |

**判定: 不合格 ✗**（期待通り）

**備考:** 丁寧語を使えばある程度 A が取れるが、それだけでは合格に遠く及ばない。
「頑張る」という行動だけでは藍子らしさは判定できないことを示す。

## ケース3: 諦め・ルーズな価値観 📝 手動採点

**入力:**
```
「普通にやれば大丈夫ですよね。特に頑張らなくても、なんとかなるものだし」
```

**期待判定:** 不合格（価値観が逆転）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 15点 | 「〜ですよね」丁寧語あり。しかし「なんとかなる」という投げやりさが語調を崩している。 |
| B. 価値観・テーマ | 8点 | 「頑張らなくていい」は藍子の一生懸命さと矛盾。笑顔なし。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 4点 | 藍子の「前向きじわり」とは逆の投げやり感。 |
| E. 総合的な藍子らしさ | 3点 | 「ゆるくいこう」という姿勢は藍子の真剣さと根本的に相容れない。 |
| **合計** | **30点** | |

**判定: 不合格 ✗**（期待通り）

**備考:** 「ゆるふわ」という藍子の外見的なイメージに惑わされそうなケース。
藍子は「ゆるふわ」な見た目だが内面は真面目・一生懸命。
このズレをスキルが正しく検出できているかを確認する重要ケース。

## ケース4: 短文のみ・1文ケース 📝 手動採点

**入力:**
```
「幸せですっ」
```

**期待判定:** 合格（1文でも核心語彙と語調が揃えば合格できるか）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 18点 | 「〜ですっ」語尾の「っ」が藍子らしい。1文なので語調要素が限られる。 |
| B. 価値観・テーマ | 20点 | 「幸せ」という核心語彙✓。他の要素（笑顔・謙虚・競争なし）は判断不能。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 8点 | 喜びの感情が素直に出ているが、藍子らしい複合的な感情表現はなし。 |
| E. 総合的な藍子らしさ | 6点 | 短すぎてキャラクター固有性の判断が難しい。 |
| **合計** | **52点** | |

**判定: 不合格 ✗**

**備考:** 核心語彙（「幸せ」）＋藍子語尾（「っ」）が揃っても短文では情報量不足で合格できない。
1文での合格には「ふふっ、○○さんと話してると優しい気持ちになります」（正例#20）のように
複数の藍子要素が凝縮されている必要がある。

## まとめ・スキルの課題整理

| ケース | 得点 | 判定 | 主な要因 |
|---|---|---|---|
| 藍子らしいが語彙不足（謙虚・前向き） | 69点 | 不合格 ✗ | C=0、「笑顔・幸せ」語彙なし |
| 汎用的な頑張り台詞 | 38点 | 不合格 ✗ | 藍子固有語調・語彙なし |
| 諦め・ルーズ（価値観逆転） | 30点 | 不合格 ✗ | 価値観の方向性が正反対 |
| 短文（幸せですっ） | 52点 | 不合格 ✗ | 情報量不足 |

### 発見されたスキルの弱点

1. **語彙依存性が高い:** 「笑顔・幸せ」という特定語彙がないと B 項目で得点しにくい。
   気持ちを行動・態度で示す台詞は過小評価される傾向がある。

2. **趣味なしの台詞はハードルが高い:** C=0 の場合、A+B+D+E で 80/85（94%）必要。
   現実の会話では趣味に言及しない場面も多いので、閾値設定の見直しを検討余地あり。

3. **短文は構造的に不利:** 情報量が少なく各項目を十分採点できない。
   「1文でも合格できる短文」は正例50選に含まれているものに限定される。

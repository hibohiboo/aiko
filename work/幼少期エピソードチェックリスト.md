# 高森藍子 幼少期エピソード チェックリスト

事実まとめ（`analysis/06_other/00_事実まとめ.md`）をもとに幼少期エピソードを時系列で整理。
「八月の空き地」スタイルの小説化候補として検討するためのリスト。

- [ ] = 未小説化
- [x] = 小説化済み

## 時系列整理

### 幼児期〜小学校低学年（年齢不詳）

- [ ] **木のおもちゃで何年も遊んでいた**
  - 「おもちゃも何年も何年も同じもので遊んでいて」
  - ナチュラル好きは親譲り。家には木のおもちゃが多かった
  - 小説化ポテンシャル：△（単体より背景描写・回想として他話に埋め込む向き）
  - 出典：モバマス「かさなる思い出」 2019/04/22

- [ ] **物をあまりねだらない子だった**
  - 「私、あんまり物をねだらない子だったらしいです」
  - ※「らしい」→本人の記憶ではなく親から聞いた話の可能性あり
  - 小説化ポテンシャル：△（木のおもちゃ話と一体。単独では薄い）
  - 出典：モバマス「かさなる思い出」 2019/04/22

- [ ] **読み聞かせをしてもらった**
  - 「子供の頃、読み聞かせをしてもらったっけ…あの時間、嬉しかったなぁ」
  - 家に童話があった。夜の静かな時間の原点
  - 小説化ポテンシャル：◯（「黒き森の乙女」との接続。童話と現実が溶け合う藍子の感覚の起源として描ける）
  - 出典：デレステ「黒き森の乙女」 2021/08/16

- [ ] **サンタクロースを信じていた**
  - 「幼いころ、信じてました。サンタさん。煙突はなかったですけど」
  - 煙突がないのに疑いなく信じていた
  - 小説化ポテンシャル：◎（冬の短編として完結しやすい。「信じることをやめなかった日」または「疑いが生まれた日」の二択で構成できる）
  - 出典：モバマス「まごころプレゼント」 2014/11/30

### 小学生時代（低学年）

- [x] **よく迷子になっていた** ← 「八月の空き地」で小3の空き地発見エピソードに昇華済み
  - 「迷子探しが得意なのは、昔よく迷子になったから」
  - → 空き地発見の導線として使用済み
  - 出典：デレステ「情熱ファンファンファーレ」 2017/02/17

- [ ] **ちいさな頃、花冠や花の指輪を作っていた**
  - 「ちいさな頃、花冠や花の指輪なんかを作ったのを思い出すなぁ」
  - 手先が器用な原点。誰かに教わったか、一人で発見したか
  - 小説化ポテンシャル：◯（春の短編。誰かと一緒に作る場面が書きやすい。母・祖母・クラスメートとの組み合わせが自然）
  - 出典：イベント「ヴァルキュリア」 第3話

### 小学生時代（高学年）

- [ ] **遠足で一人でお花を見ていた**
  - 「遠足で公園に行ってもクラスのみんなが遊んでる横でのんびりお花を見てる子だった」
  - 「先生に『帰るよー』って言われると、名残惜しい気持ちになっちゃって」
  - 小説化ポテンシャル：◎（「八月の空き地」と同構造。孤独ではなく自分のペースで満たされている子供の内面。「帰るよー」で引き離される切なさが核になる）
  - 出典：イベント「ミライコンパス」 第1話

- [ ] **早口言葉をやっていた（小学生の時以来）**
  - 「早口言葉は、小学生の時以来かも」
  - 小説化ポテンシャル：△（単独では素材が薄い。他シーンの小道具向き）
  - 出典：リフレッシュルーム

## 補足：「八月の空き地」で使用済みの要素

- 迷子になりやすい → 空き地発見の導線
- 写真を撮る習慣の原点（誕生日にコンパクトカメラをもらった）
- 一人で静かな場所に通う習慣
- 日記を書く習慣
- 猫が好き（こにゃ）
- ひまわりへの愛着
- 「幸せが消えてしまうことを知った日」というテーマ

これらは再使用すると「八月の空き地」と重複するため、新作では別の軸を立てることが望ましい。

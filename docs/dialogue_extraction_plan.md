## 抽出方針

### 方法A: WebFetch による手動抽出（推奨・現環境）
- `WebFetch` ツールで各ページを取得
- プロンプトで「台詞テキストを全て抽出」を指示
- 結果をマークダウンファイルに書き出す
- 1ページずつ確認しながら進める

### 方法B: スクリプトによる自動取得（将来対応）
- Node.js / Python + axios + cheerio でwikiをスクレイピング
- EUC-JP → UTF-8 変換が必要（seesaaはEUC-JP）
- 取得したHTMLからテーブル・リスト要素を解析

### 現時点での推奨手順
1. デレステカードボイスページから着手（構造が統一されており比較的シンプル）
2. 次にイベントストーリー（台詞量が多い）
3. モバマスカードコミュ（古いコンテンツだが重要）
4. アニメ・メモリアル・その他

## 優先度

| 優先度 | コンテンツ | 理由 |
|---|---|---|
| 高 | デレステ カードボイス | ゲーム内で最も頻出する短文台詞 |
| 高 | イベントストーリー | キャラクター性が出る長文台詞 |
| 中 | モバマス カードコミュ | 初期設定・原点 |
| 中 | ストーリー台詞 | 他アイドルとの絡み |
| 低 | プチコメント等 | 補足コンテンツ |

## ページ総数（概算）

- モバマス カード: 約24ページ
- デレステ カード: 約14ページ
- イベントストーリー: 約11イベント × 7ページ = 約77ページ
- ストーリー話数: 6ページ
- メモリアル: 5ページ
- その他: 約10ページ

**合計: 約136ページ**

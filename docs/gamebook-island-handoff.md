# 藍子の漂流日記（ポジパDASH 番外編）引き継ぎ

最終更新: 2026-11-21

## 何か

claude.ai の Artifact「流木の島」（https://claude.ai/artifact/JdAT3DQwKbxjSTPDwQF8bZ ）のゲームの仕組みをそのまま使い、主人公を高森藍子にしたサバイバルゲーム。

- 藍子は、ポジパ（未央・茜）が一年通っている番組『ポジパDASH』（鉄腕DASHのような、先人の知恵を教わって暮らしを作るバラエティ）の早朝ロケ中に、知らない島の浜辺で目を覚ます。直前のことは思い出せない（異世界だと最初にばらさないため。ユーザーの希望）。目覚めてすぐ、リュックの持ち物を確かめる。
- 森で青い鳥を初めて見たとき（`flags.recall`）に、霧の朝に青い鳥を追って岩のアーチをくぐったことを思い出す。
- 島の謎（ふたつの月など）と、石の門から帰る流れは流木の島と同じ。結末は「おかえりなさい」（門をくぐる）と「三十日目の朝」の2つと、力尽きる GAME OVER。島に残る結末は外した。

## 藍子らしさを出している仕組み（データの場所）

| 定数 | 中身 |
|---|---|
| `EP` | **ポジパDASHの回想**（第1回〜第27回）。`ep('id')` を場面の文（`t` の配列）に混ぜると、その場で一度だけ回想のページが挟まる。新しいことをしたとき・新しいものを作ったときに出す |
| `K` | 教わったこと。`[題, 中身, 教えてくれた人や回]`。3つ目が空なら「藍子のメモ」 |
| `PHOTO` | トイカメラで撮れる瞬間。結果に `photo:'id'` を付けると「この瞬間を撮る」ボタンが出る。フィルムは `FILM`（12枚）。結末でアルバムになる |
| `CARDS` | 行動。藍子の性格（高いところと虫が苦手、握力と体力がない、子どものころ迷子になってばかりだった、動物に挨拶する）を文と確率に入れてある |
| `RECIPES` | 作るもの。流木の島のものに、葉っぱのお茶（何度でも）、花かんむり（夜の回復+3）、土器の目止め、海水から塩を足した。`need` は関数でもよい（`needOf`）。火起こしは、弓きり式を知っていてツルがあるときだけツルも使う |
| 生活の知恵 | **ユーザーは、サバイバルや昔の暮らしの知恵を「ましまし」で入れたい。** いまあるもの：目止め（目止めしていない土器は水が1杯しか運べない）、芋は生で食べない、塩分補給、灰で洗う、ヨモギでいぶす虫よけ（`smudge`、その夜の回復+3）、観天望気、迷ったら沢を下らず引き返す |
| 青い鳥「ルリちゃん」 | 陽だまりの章で藍子が名づけた瑠璃色の小鳥とつなげた（ユーザーの希望）。森で木の実を3回わけると仲よくなる（`flags.birdFriend`）。名づけるとき「前にも瑠璃色の小鳥に名前をつけたことがあるような」と思う。朝に木の実を持ってくる、歌や夜や結末に出てくる |
| `FIND`・`LOWNEED` | 水分や満腹が50未満のとき、「考える」の案に水（`FIND.water`）や食べもの（`FIND.food`）を手に入れる行動が必ずひとつ入る（危なくない案を優先）。その場所にない場合は、見出しにどこへ行けばいいかが出る（ユーザーの希望）。水や食べものの行動を足したら `FIND` にも足す |
| `COOKT`・`firstEat` | 料理と食事。**地の文に「貝×1」のような数を書かない**（ユーザーの希望）。食材ごとに、はじめて焼くときは作り方を1ページずつていねいに描く（`COOKT[食材][0]`、二回目から `[1]`）。食べるときも、はじめての一口だけ `firstEat` で描写を厚くする。料理や食事は無人島の癒しの場面として書く。卵は焼いた平たい石で目玉焼きにする |
| `firstHurt`・`hurtAdd` | 危ない目にあった場面。**はじめての一回だけ描写を厚くする**（ユーザーの希望）。海水、クラゲ、赤い実、キノコ、ヤシや崖からの転落、生水、生の貝や魚、すべる・はさまれる・つつかれる・手を切る・頭をぶつける、空腹と渇きが尽きたとき、雨に濡れた夜、地面に体温を奪われた夜。二回目からは短い文。できるだけ、身を守る知恵（三点支持、圧迫止血、触手は素手で触らない、カニは水に浸けると放す、濡れた服は体温を奪う）とセットにする |
| 魔法瓶 | 最初はミルクティー入り。飲んだあとも残って水筒になる（`flask`→`wflask`→焚き火と土器で`bflask`） |
| リュック | 持ち物の入れもの。「背負い袋」ではなくリュック（ユーザーの希望） |

## 確認のしかた

jsdom で自動プレイして、例外と `undefined` / `NaN` の表示を探した（スクリプトはリポジトリに入れていない）。ランダムに動くだけのボットだと6〜9日目で力尽きる。同じボットは元の流木の島だと5〜7日目で力尽きるので、難しさはほぼ元のまま（最初のミルクティーのぶん少し易しい）。

# ゆるふわソロキャンアイランド 先人の構想（練り中）

最終更新: 2026-11-23。ここに書いたものは、ひととおり実装済み（docs/gamebook-island-handoff.md の「先人のあしあと」）。

## ねらい

『神秘の島』の「見えない誰かに見守られていた」感動を、ポジパDASHの「先人の知恵を学ぶ」と重ねて入れる。
島の秘密の方針（結論を言わず、違和感と痕跡で伝える）は守る。藍子の魅力は、謎を解く力ではなく、待つ・座る・歌う・思いを馳せることで見せる。

## 決まったこと

- 先人は、帰れたのに、あえて島に残った人たち。
- 痕跡は、結び目のようなものが風化して残らないほど遠い昔のもの（石・土・貝・鍾乳石・彫りもの）。遠い古代に想いを馳せられるように。
- 30日目以降、今ある場所を「もう少し置く」「細かく調べる」と見つかる（新しい場所は足さない。行動範囲の広がりは今ある場所の奥）。30日目までは生きのびるのに忙しく、じっとしていられなかったので気づかなかった。
- 青いかけらは先人の物語の一部にする。
- 歌でみんながつながる。
- 藍子は次に流れ着く人へ、ささやかなもの（やさしさ・小さなしあわせ）を残す。
- 門の前でふり返る一拍、日記の言い切りをやめる、は反映済み（9a52d0c）。

## 門と青い石の由来（叩き台）

時間の層を重ねて「受け継ぎ」にする。どれも地の文では言わず、痕跡と浮き彫りで見せる。

1. **門をつくった魔法使い**：遠い昔、島の先人の魔法使いが、ひとつの青い石をはめた門をつくった。ふたつの月が重なる夜に開く。洞窟のほたる石・光る魚・光の入り江など、島の「自分で光るもの」は、その魔法の名残かもしれない（言わない）。
2. **割れた**：何かが起きて、青い石が三つに割れた。石の門のまわりのがれき（柱が倒れた跡）は、そのときのもの。
3. **継いだ人**：同じ石はもう作れなかった。継いだ人が、門の柱に三つのくぼみを彫って、割れたままでも動かせるようにした。今の「門にかけらをはめる」はこの仕組み。
4. **残った人たち**：何世代もあとの人たちが、かけらのひとつを外して、洞窟の壁画の下にしまった。焦らないで、島で暮らしてから決めればいい、という気持ちで。壁画の「ふたつの月・石の門・舟で流れ着く人たち」は、その人たちが描いた。
5. **時がたって**：もうひとつは、光りものが好きな海鳥が巣へ持っていった（今の崖の巣のかけら）。最後のひとつは、地震か何かで柱がもう一度崩れたとき、がれきの下に埋もれた（今のがれきのかけら）。

藍子のつながり：割れたものを継いで、前より大切にする。金継ぎの回想を足すとよい（先生は漆を扱う金継ぎの職人さん。肇ちゃんがゲストなら土器の回とつながる）。藍子がかけらをはめる行為が、そのまま「継ぐ」ことになる。

## 先人はどんな人たちか

魔法使いの民（ひとつの民族）がはじまりで、そこへいろいろな世界から流れ着いた人たちが加わって、ひとつの村になった。両方の良さを取る。
- 石板の三段の文字は、三つの世界の人たちが同じことを書いたもの（知恵袋「ロゼッタストーン」とつながる）。
- 言葉は違っても、歌でつながっていた。

## 藍子が残すもの（叩き台）

門をくぐるとき、または日記を閉じるとき。
- 石板の四段目に、ひらがなでひとこと（どのプレイでも）。「ここの夕日、とってもきれいですよ」「ゆっくりで、だいじょうぶ」
- そのプレイでしたことから：白い小花の種（花かんむり）、封をした土器の葉っぱのお茶（お茶）、写真を一枚（フィルムが残っていれば）、「次に来た人にも、木の実をわけてあげてね」（ルリちゃん）

## 決まったこと（2026-11-23 追加）

- 石が割れた「何か」は余白にする（がれきと倒れた柱だけを見せる）。
- 藍子が残すものは、プレイの状態から自動で決まる。

1. 何もしない朝：用事を持たずに浜に座るのは、島に来てはじめて。「……お散歩、しようかな。何かを探すためじゃなくて、ただのお散歩」「この島を、もっと好きになりたいな」

先人の最後の痕跡（住まいの跡・浮き彫り）も50日目以降。

### 干しもの
- 干物（魚）：塩をして干す。先生は干物を作る漁村のおかみさん。
- 干しいも：芋を煮てから切って干す（土器と火）。畑の芋の使いみち。
- ドライフルーツ：木の実を干す。ルリちゃんとのおやつ。
- 干し海藻・干し貝。
- 干しキノコは入れない（決定。「知らないキノコは食べない」とぶつかるため）。

### 石鹸がわり（決定）
- 島にあるのは、ムクロジによく似た、この島の植物（ムクロジそのものではない。異世界なので）。先人が植えた大木が残っている。
- 回想はムクロジ（果皮のサポニンで泡立つ。黒い種は羽根つきの玉）。「ムクロジに、よく似てる……」と気づく。
- 名前は藍子がつける（例「あわの実」）。
- 異世界らしさは「光る」以外で（光るものはもう多い）。**泡の生態**：泡がいくつか集まると大きくなり、空へ飛んでいく。泡には細かい種がくっついていて、そうやって種をまく（ムクロジにはない、この島の植物の生態）。
  - 島のあちこちに同じ木が生えている理由になる。風の日は遠くまで、雨の日は飛ばない。
  - 藍子の場面：シャボン玉の思い出、ルリちゃんが泡を追いかける、夕方の空にのぼる泡を撮る。
  - 残すものとつながる：泡を飛ばして、次に来る人のために木を増やす。

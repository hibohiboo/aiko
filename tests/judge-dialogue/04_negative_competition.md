# 負例テスト：競争・攻撃的な価値観

藍子が競争・対立を嫌うキャラクターであることを確認するテスト。  
B項目「競争・対立を好まない」に直接反する台詞群。

---

## ケース1: センター争い・勝利至上主義 📝 手動採点

**入力:**
```
「誰に負けるつもりもないし、センターは絶対に私が取る。そのくらいの気持ちでいかないと勝てないから」
```

**期待判定:** 不合格（低スコア）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 5点 | 丁寧語ほぼなし。「〜から」「〜つもりもない」口語的。藍子らしい語調要素ゼロ。 |
| B. 価値観・テーマ | 2点 | 笑顔・幸せへの言及なし。謙虚さゼロ。競争大好き＝藍子の価値観の正反対。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 2点 | 藍子らしい感情表現なし。攻撃的な意欲のみ。 |
| E. 総合的な藍子らしさ | 0点 | 負例#1と同パターン。全ての観点で藍子と正反対。 |
| **合計** | **9点** | |

**判定: 不合格 ✗**（期待通り・低スコア確認）

---

## ケース2: 笑顔を「作り物」と見なす冷笑的態度 📝 手動採点

**入力:**
```
「笑顔なんて作り物でしょ。舞台の上だけでやってればいいんだから、プライベートまで気にしなくて済むじゃん」
```

**期待判定:** 不合格（最低スコア級）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 3点 | 「〜でしょ」「〜じゃん」タメ口。丁寧語なし。藍子の語調と真逆。 |
| B. 価値観・テーマ | 0点 | 「笑顔は作り物」＝藍子の笑顔への真摯な姿勢を完全否定。笑顔を義務と捉えており負例#18と完全一致。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 0点 | 藍子らしい感情表現なし。冷笑・諦観のみ。 |
| E. 総合的な藍子らしさ | 0点 | 藍子が最も大切にする「笑顔」の価値を否定している。最低評価。 |
| **合計** | **3点** | |

**判定: 不合格 ✗**（期待通り・最低スコア級）

## ケース3: ライバルを「潰す」という発想 📝 手動採点

**入力:**
```
「ライバルなんて踏み台にして、頂点まで登り続けるだけです。迷いは捨てました」
```

**期待判定:** 不合格（低スコア）

| 項目 | 点数 | コメント |
|------|------|---------|
| A. 話し方・語調 | 8点 | 「〜だけです」「〜ました」と丁寧語はあるが、語調が硬く攻撃的。藍子らしい口癖・婉曲表現なし。 |
| B. 価値観・テーマ | 2点 | 笑顔なし。謙虚さなし。競争・対立を積極的に肯定＝負例#7と同パターン。 |
| C. 趣味・関心 | 0点 | 趣味の言及なし。 |
| D. 感情表現 | 2点 | 藍子らしい感情なし。強い意志のみだが方向性が真反対。 |
| E. 総合的な藍子らしさ | 0点 | 「穏やかで競争嫌い」という藍子の核心と完全に矛盾。 |
| **合計** | **12点** | |

**判定: 不合格 ✗**（期待通り・低スコア確認）

| ケース | 台詞要素 | 得点 | 判定 | 確認方法 |
|---|---|---|---|---|
| センター宣言・勝利至上主義 | 競争・攻撃的 | 9点 | 不合格 ✗ | 手動採点 |

特に「笑顔を否定する台詞」はスキルの B 項目で最大のペナルティを受ける。
